# 测试底图来源与限制

本目录的 `outpatient-1f.jpg`、`outpatient-2f.jpg`、`outpatient-3f.jpg`
来自东方市人民医院公开页面的楼层分布图：

- http://www.hndfsrmyy.com/w/155.html

它们仅用于 MedRoute 的本地功能验证和示例演示。页面上叠加的 POI 坐标、
路线、A/B 电梯编号、楼梯编号和楼层可达关系都是本项目的测试数据，不代表医院
的正式导诊信息，也不能作为就医路线依据。

在用于任何公开部署、生产环境或实际导诊前，应取得权利方许可，并替换为经过
现场核验和发布流程确认的地图版本与路网数据。
