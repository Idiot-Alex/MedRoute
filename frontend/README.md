# MedRoute 新版前端

该目录是 Vue 3、TypeScript、Tailwind CSS 和 OpenLayers 前端工作区。新版与
`hospital-map-demo` 并行运行，按功能迁移，不影响现有验收入口。

## 目录

```text
apps/map-admin-web/       电脑端楼层图维护
apps/navigation-web/      移动端路线查看
packages/api-client/      后端 API 客户端和演示数据
packages/map-core/        领域类型、图操作、坐标和 OpenLayers 图层
public/                   两个应用共享的本地测试底图
```

## 安装和启动

需要 Node.js 20 或更高版本和 pnpm 10。

```bash
pnpm install
```

维护端：

```bash
pnpm dev:admin
```

导航端：

```bash
pnpm dev:navigation
```

默认后端为 `http://127.0.0.1:8080`，也可以通过查询参数指定：

```text
http://127.0.0.1:5173/?api=http://127.0.0.1:8080
http://127.0.0.1:5174/?api=http://127.0.0.1:8080
```

后端未启动时使用本地演示数据：

```text
http://127.0.0.1:5173/?demo=1
http://127.0.0.1:5174/?demo=1
```

演示模式不会写数据库，所有标注、发布和回滚只在当前维护页面会话内生效，
不会切换另一个标签页中的导航端数据。

## 当前能力

维护端支持：

- 节点新增和拖动、两节点连路、POI 绑定
- 电梯和楼梯设施创建及属性维护
- 按实际停靠楼层将设施绑定到路径节点
- 显式配置任意两个停靠楼层之间的方向、耗时和无障碍属性
- 跨层引用、重复停靠、孤立停靠和连接拓扑检查
- 后端草稿读取及 ETag 并发保护保存
- 发布版本、历史版本和草稿切换，以及草稿创建和放弃
- 楼层底图替换前后预览、尺寸变化风险提示和坐标自动缩放
- 关键路线新增、编辑、删除和发布前自动回归
- 完整后端校验结果定位、校验通过后发布和历史版本回滚

导航端支持：

- 按名称、稳定编码、分类、楼层、中文别名和维护关键词搜索起终点
- 常规/无障碍模式和稳定 POI 编码深链，失效链接自动回退并提示
- 同层及跨楼层路线展示、完整步骤列表和逐条路线说明
- 当前步骤切换时自动联动对应楼层地图

可分享或制作固定点二维码的导航地址使用稳定业务编码：

```text
http://127.0.0.1:5174/?building={buildingId}&startPoi={poiCode}&endPoi={poiCode}&routeMode=normal
```

连接真实后端时，维护端发布或回滚会切换数据库中的当前发布版本，导航端随后读取
该版本。演示模式只用于验证界面和工作流，不用于跨应用联调。

## 验证

```bash
pnpm test
pnpm typecheck
pnpm build
```

维护端验收 `1200 x 720` 和 `1440 x 900`；导航端验收 `360 x 800`、
`390 x 844` 和 `430 x 932`。

## 数据约束

- 后端 `DraftGraph` 和路线响应是唯一业务数据源。
- 数据库存储左上角原点、Y 轴向下的楼层图片像素坐标。
- OpenLayers 使用 Y 轴向上的地图坐标，只能通过 `map-core` 边界转换。
- 路径几何由起止节点实时生成，不独立持久化折线坐标。
- 电梯和楼梯不会默认连通所有楼层；只有已维护的停靠点和跨层连接可用于导航。
- 同一设施每层最多一个停靠点，停靠点必须绑定该层路径节点。
- 导航端不加载草稿，也不在浏览器计算正式路线。
