# 数据库设计

## 1. 技术选型

推荐：

```text
PostgreSQL + PostGIS
```

第一版即使不用复杂空间查询，也建议使用 PostgreSQL，为后续多医院扩展做准备。

## 2. 启用 PostGIS

```sql
CREATE EXTENSION IF NOT EXISTS postgis;
```

## 3. 核心表

### 3.1 hospital

```sql
CREATE TABLE hospital (
  id BIGSERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  city VARCHAR(50),
  address VARCHAR(255),
  status VARCHAR(20) DEFAULT 'enabled',
  created_at TIMESTAMP DEFAULT now(),
  updated_at TIMESTAMP DEFAULT now()
);
```

### 3.2 building

```sql
CREATE TABLE building (
  id BIGSERIAL PRIMARY KEY,
  hospital_id BIGINT NOT NULL REFERENCES hospital(id),
  name VARCHAR(100) NOT NULL,
  code VARCHAR(50),
  created_at TIMESTAMP DEFAULT now(),
  updated_at TIMESTAMP DEFAULT now()
);
```

### 3.3 floor

```sql
CREATE TABLE floor (
  id BIGSERIAL PRIMARY KEY,
  hospital_id BIGINT NOT NULL REFERENCES hospital(id),
  building_id BIGINT NOT NULL REFERENCES building(id),
  name VARCHAR(50) NOT NULL,
  level_no INT NOT NULL,
  created_at TIMESTAMP DEFAULT now(),
  updated_at TIMESTAMP DEFAULT now()
);
```

### 3.4 floor_map

```sql
CREATE TABLE floor_map (
  id BIGSERIAL PRIMARY KEY,
  hospital_id BIGINT NOT NULL REFERENCES hospital(id),
  building_id BIGINT NOT NULL REFERENCES building(id),
  floor_id BIGINT NOT NULL REFERENCES floor(id),
  image_url VARCHAR(500) NOT NULL,
  image_width INT NOT NULL,
  image_height INT NOT NULL,
  version VARCHAR(50) DEFAULT 'v1.0',
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT now(),
  updated_at TIMESTAMP DEFAULT now()
);
```

### 3.5 path_node

坐标使用图片像素坐标。

```sql
CREATE TABLE path_node (
  id BIGSERIAL PRIMARY KEY,
  hospital_id BIGINT NOT NULL REFERENCES hospital(id),
  building_id BIGINT NOT NULL REFERENCES building(id),
  floor_id BIGINT NOT NULL REFERENCES floor(id),
  code VARCHAR(80) NOT NULL,
  x DOUBLE PRECISION NOT NULL,
  y DOUBLE PRECISION NOT NULL,
  node_type VARCHAR(30) DEFAULT 'normal',
  enabled BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT now(),
  updated_at TIMESTAMP DEFAULT now(),
  UNIQUE(hospital_id, code)
);
```

### 3.6 path_edge

```sql
CREATE TABLE path_edge (
  id BIGSERIAL PRIMARY KEY,
  hospital_id BIGINT NOT NULL REFERENCES hospital(id),
  from_node_id BIGINT NOT NULL REFERENCES path_node(id),
  to_node_id BIGINT NOT NULL REFERENCES path_node(id),
  distance DOUBLE PRECISION NOT NULL,
  walk_time INT,
  accessible BOOLEAN DEFAULT true,
  edge_type VARCHAR(30) DEFAULT 'walk',
  status VARCHAR(30) DEFAULT 'enabled',
  remark VARCHAR(255),
  created_at TIMESTAMP DEFAULT now(),
  updated_at TIMESTAMP DEFAULT now()
);
```

edge_type：

```text
walk
elevator
stair
escalator
virtual
```

### 3.7 poi

```sql
CREATE TABLE poi (
  id BIGSERIAL PRIMARY KEY,
  hospital_id BIGINT NOT NULL REFERENCES hospital(id),
  building_id BIGINT NOT NULL REFERENCES building(id),
  floor_id BIGINT NOT NULL REFERENCES floor(id),
  node_id BIGINT REFERENCES path_node(id),
  name VARCHAR(100) NOT NULL,
  category VARCHAR(50),
  x DOUBLE PRECISION NOT NULL,
  y DOUBLE PRECISION NOT NULL,
  search_keywords VARCHAR(500),
  remark TEXT,
  enabled BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT now(),
  updated_at TIMESTAMP DEFAULT now()
);
```

### 3.8 route_feedback

```sql
CREATE TABLE route_feedback (
  id BIGSERIAL PRIMARY KEY,
  hospital_id BIGINT NOT NULL REFERENCES hospital(id),
  start_poi_id BIGINT REFERENCES poi(id),
  end_poi_id BIGINT REFERENCES poi(id),
  feedback_type VARCHAR(50),
  content TEXT,
  created_by VARCHAR(100),
  created_at TIMESTAMP DEFAULT now()
);
```
