# 接口设计

## 1. 查询医院列表

```http
GET /api/hospitals
```

响应：

```json
[
  {
    "id": 1,
    "name": "测试医院",
    "city": "上海"
  }
]
```

## 2. 查询楼层地图

```http
GET /api/hospitals/{hospitalId}/floors/{floorId}/map
```

响应：

```json
{
  "floorId": 1,
  "name": "1F",
  "imageUrl": "/maps/test-hospital/floor-1.png",
  "imageWidth": 1000,
  "imageHeight": 600
}
```

## 3. 查询 POI

```http
GET /api/hospitals/{hospitalId}/pois?keyword=药房
```

响应：

```json
[
  {
    "id": 4,
    "name": "药房",
    "category": "pharmacy",
    "floorId": 1,
    "x": 800,
    "y": 390,
    "nodeId": 6
  }
]
```

## 4. 查询楼层路网

```http
GET /api/hospitals/{hospitalId}/floors/{floorId}/graph
```

响应：

```json
{
  "nodes": [
    { "id": 1, "code": "N1", "x": 160, "y": 420 }
  ],
  "edges": [
    { "from": 1, "to": 2, "distance": 10 }
  ],
  "pois": [
    { "id": 1, "name": "挂号处", "nodeId": 1, "x": 130, "y": 390 }
  ]
}
```

## 5. 路线规划

```http
POST /api/routes
Content-Type: application/json
```

请求：

```json
{
  "hospitalId": 1,
  "startPoiId": 1,
  "endPoiId": 4,
  "routeMode": "normal"
}
```

响应：

```json
{
  "hospitalId": 1,
  "startPoi": {
    "id": 1,
    "name": "挂号处"
  },
  "endPoi": {
    "id": 4,
    "name": "药房"
  },
  "distance": 44,
  "estimatedTime": 120,
  "path": [
    { "nodeId": 1, "floorId": 1, "x": 160, "y": 420 },
    { "nodeId": 2, "floorId": 1, "x": 320, "y": 420 },
    { "nodeId": 3, "floorId": 1, "x": 480, "y": 420 },
    { "nodeId": 4, "floorId": 1, "x": 650, "y": 420 },
    { "nodeId": 6, "floorId": 1, "x": 820, "y": 420 }
  ],
  "steps": [
    "从挂号处出发，进入主通道。",
    "沿主通道直行，经过收费处附近。",
    "继续直行到走廊节点。",
    "前行到达药房。"
  ]
}
```

## 6. 路线模式

建议预留：

```text
normal       普通路线
accessible   无障碍路线
less_elevator 少乘电梯
staff         内部路线
```

第一版只实现 normal。
