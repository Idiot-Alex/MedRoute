# 医院室内路线引导系统文档

本套文档用于搭建一个支持多医院的室内路线引导平台。项目已从单层 Demo
推进到可持久化、可维护和可发布的三层最小可用版本：

- 每层上传独立医院楼层图并标注 POI、节点和路径边
- 明确维护电梯、楼梯的停靠楼层及实际层间通道
- 创建草稿、自动校验、发布和回滚完整楼栋导航图
- 临时停用路径或跨层设施，并立即影响后端路线计算
- 用户选择起终点后，在对应楼层图上查看路线和跨层指引

> 项目定位：不是实时定位导航，而是“关键点到关键点”的室内路线引导系统。

## 当前实现

- `hospital-map-demo/`: 保留单层 Demo，新增多楼层导航页和地图维护后台。
- 用户导航页移动优先；地图维护后台桌面优先，两端共享 API 但保持独立入口和布局。
- `hospital-navigation-server/`: Spring Boot 模块化单体；正式导航读取 PostgreSQL
  当前发布图，支持 Dijkstra 跨层路线、草稿维护、校验、发布、回滚、底图上传
  和持久化运营封闭。
- `compose.yaml`: PostgreSQL 16 本地开发数据库；Flyway 在后端启动时自动迁移。
- 当前下一步是生产化：接入正式认证和楼栋权限，导入经授权的真实医院数据，
  完成现场走查和固定路线回归。
