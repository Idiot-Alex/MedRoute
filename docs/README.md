# 医院室内路线引导系统文档

本套文档用于搭建一个支持多医院的室内路线引导平台，第一阶段目标是先做出一个单层楼 Demo：

- 上传/准备一张医院楼层示意图
- 标注 POI、路径节点和路径边
- 用户选择起点和终点
- 系统计算最短路线
- 前端在地图上高亮路线并展示文字指引

> 项目定位：不是实时定位导航，而是“关键点到关键点”的室内路线引导系统。

- `hospital-map-demo/`: 阶段一静态单层路线引导 Demo，包含导航页、路网数据和地图编辑器。
