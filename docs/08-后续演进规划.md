# 后续演进规划

## 阶段一：单层 Demo

目标：

- 一张楼层图
- 几个 POI
- 几条路径边
- 起点终点路线规划
- 地图高亮

## 阶段二：接入后端和数据库

目标：

- PostgreSQL 存储医院、楼层、POI、节点、边
- Spring Boot 提供接口
- 前端从接口加载数据
- 后端执行 A*

## 阶段三：多楼层

目标：

- 支持电梯
- 支持楼梯
- 支持跨楼层路线
- 分楼层显示路径
- 步骤中提示“乘电梯到 X 楼”

## 阶段四：多医院

目标：

- 支持几十家医院
- 医院切换
- 楼栋切换
- 地图版本管理
- 数据权限

## 阶段五：地图编辑后台

目标：

- 上传楼层图
- 鼠标标注节点
- 拖动节点
- 连接路径边
- 标注 POI
- 绑定 POI 到节点
- 发布地图版本

## 阶段六：陪诊业务增强

目标：

- 订单关联目的地
- 常用路线
- 陪诊员经验备注
- 路线反馈
- 施工/封闭提醒
- 无障碍路线

## 阶段七：可选智能增强

在不增加硬件的前提下，可考虑：

- OCR 识别科室牌
- 拍照识别当前位置
- 医院导览牌识别
- 常用起点推荐
- 根据订单自动推荐路线

这些都不是第一阶段必须做。
