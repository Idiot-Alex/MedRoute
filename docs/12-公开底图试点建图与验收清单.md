# 公开底图试点建图与验收清单

## 1. 使用边界

本清单用于验证 MedRoute 能否完成一栋多楼层医院建筑的建图、校验、发布和手机
导航闭环。当前试点使用东方市人民医院公开页面中的三张门急诊楼分布图，但点位
坐标、路径距离、通行时间、电梯编号和停靠楼层均为开发测试数据。

试点结果不能作为医院正式导诊信息。公开部署前必须取得底图使用许可，并由医院
指定人员完成现场核验和书面确认。

底图来源和限制见：

- `hospital-map-demo/assets/hndfsrmyy/README.md`
- <http://www.hndfsrmyy.com/w/155.html>

## 2. 试点草稿

Flyway V9 预置以下可编辑草稿：

```text
楼栋：门急诊楼
草稿编码：PILOT-DFSRMYY-001
草稿 ID：00000000-0000-0000-0000-000000000300
基于版本：REL-TEST-001
```

草稿保留旧发布版本，不会在数据库迁移时自动切换当前导航数据。

当前数据规模：

| 内容 | 数量 |
| --- | ---: |
| 楼层 | 3 |
| 路径节点 | 59 |
| 同层路径 | 58 |
| POI | 30 |
| 电梯/楼梯 | 3 |
| 停靠点 | 8 |
| 层间连接 | 5 |
| 关键路线 | 12 |

跨层测试关系：

- A 电梯：停靠 1F、3F。
- B 电梯：停靠 1F、2F、3F。
- A 楼梯：连接 1F、2F、3F，不允许无障碍路线使用。

## 3. 楼层点位

### 3.1 一层

门诊入口、门诊大厅服务台、导医台、急诊入口、急诊大厅、抢救室、急诊留观室、
门诊输液区、门诊药房、影像中心和无障碍卫生间。

### 3.2 二层

检验科、抽血站、口腔科、眼科、精神心理科、康复疼痛门诊、儿科门诊、妇科、
内科、外科、西药房和挂号收费。

### 3.3 三层

CCU、中医康复中心、心电图、内镜中心、超声医学科、西药房和挂号收费。

每个 POI 均维护了稳定业务编码，并至少包含中文别名、完整拼音或拼音首字母
搜索词。正式上线时应替换为医院实际使用的科室名称、简称和同义词。

## 4. 自动验收

后端测试 `DongfangPilotDraftIntegrationTest` 自动执行：

1. 核对草稿中的楼层、节点、路径、POI 和跨层设施数量。
2. 从门诊入口计算到全部 29 个其他 POI 的普通路线。
3. 对全部无障碍 POI 计算无障碍路线并确认不经过楼梯。
4. 临时启用 8 条试点路线，与原有 4 条路线组成 12 条发布回归。
5. 确认 12 条路线全部通过距离、耗时和跨层设施限制。
6. 确认入口到二层儿科的无障碍路线使用 B 电梯。

执行：

```bash
cd hospital-navigation-server
./mvnw -Dtest=DongfangPilotDraftIntegrationTest test
```

当前发布版本已存在时，还应启动 PostgreSQL 和后端，在仓库根目录执行：

```bash
MEDROUTE_EXPECTED_POI_COUNT=30 node scripts/pilot-api-smoke.mjs --write
```

该脚本直接访问真实运行 API，检查 29 条普通路线、全部无障碍路线、二维码 PNG，
并通过可逆设施封闭验证绕行/不可达和撤销后的基线恢复。

局域网手机入口还应只通过导航端公开 API 白名单执行只读回归：

```bash
MEDROUTE_API_BASE=http://192.168.5.42:5174 \
  MEDROUTE_EXPECTED_POI_COUNT=30 \
  node scripts/pilot-api-smoke.mjs --public-only
```

维护端和 Spring Boot 默认只监听 `127.0.0.1`。确认导航入口访问 `/api/admin`
返回 `404`，且局域网地址的 `8080` 无法直连；认证接入前不要放宽该边界。

## 5. 本地发布验收

1. 在 IDEA 中重启后端，确认 Flyway 已迁移到 V9。
2. 打开维护后台并选择 `PILOT-DFSRMYY-001`。
3. 逐层检查 POI 和路径是否与底图可辨识区域大致对应。
4. 在“校验”页签启用编码以 `PILOT-` 开头的 8 条路线。
5. 点击“保存并校验”，确认 12/12 关键路线通过。
6. 填写“公开底图试点自动验收”作为发布原因并发布。
7. 使用电脑局域网 IP 的 `5174` 地址打开手机导航页，搜索一层药房、二层儿科和
   三层内镜中心并规划路线。
8. 切换无障碍模式，确认跨层路线不显示楼梯。
9. 临时停用 B 电梯，确认二层无障碍目的地返回不可达或使用经现场确认的备选设施。
10. 恢复 B 电梯并确认路线恢复。

本地发布只切换开发数据库中的当前测试版本，不代表医院生产发布。

## 7. 现场核验

以下内容无法通过公开图片和自动化测试确认，必须由医院人员现场完成：

- 底图版本、方向和楼层名称是否仍然有效。
- 各科室、窗口、入口和无障碍卫生间的实际位置。
- 走廊、门禁、单向通行、夜间关闭和医务人员专用区域。
- 电梯编号、停靠楼层、运行时间和无障碍能力。
- 楼梯、坡道及轮椅通行条件。
- 每段路线的距离、平均耗时和文字指引是否容易理解。
- 固定点二维码张贴位置和手机网络可用性。

建议至少由一名地图维护人员和一名不熟悉建筑的测试人员分别走查。
