# 医院地图制作规范

## 1. 目标

统一几十家医院的室内地图制作规则，保证路线规划稳定、数据可维护、后续可扩展。

## 2. 地图层级

统一使用以下层级：

```text
Hospital 医院
  Campus 院区
    Building 楼栋
      Floor 楼层
        FloorMap 楼层图
        POI 关键点
        PathNode 路径节点
        PathEdge 路径边
```

## 3. 楼层命名规范

建议：

```text
B2
B1
1F
2F
3F
```

不要混用：

```text
一楼
1层
F1
第一层
```

## 4. POI 命名规范

POI 名称应贴近医院现场标识。

推荐：

```text
挂号处
收费处
药房
检验科
影像科
心内科
儿科门诊
3号电梯
卫生间
报告打印机
```

避免：

```text
地方A
这里
那个窗口
旁边电梯
```

## 5. POI 分类

建议分类：

```text
department      科室
window          窗口
pharmacy        药房
inspection      检查检验
elevator        电梯
stair           楼梯
toilet          卫生间
entrance        出入口
service         服务设施
machine         自助机
nurse_station   护士站
other           其他
```

## 6. 路径节点布点规范

必须布点的位置：

- 走廊拐角
- 岔路口
- 电梯口
- 楼梯口
- 科室门口
- 大厅入口
- 长走廊每隔一段距离
- 需要语音提示的位置

不要在同一条直线上布太多点。

建议：

```text
直走超过 20~30 米，可以增加一个中间节点。
```

## 7. 路径边规范

路径边只连接可通行的两个节点。

每条边建议包含：

```text
distance
walk_time
accessible
status
remark
```

status：

```text
enabled
disabled
construction
staff_only
night_closed
```

## 8. 电梯/楼梯规范

电梯和楼梯必须编号。

例如：

```text
ELEV-A
ELEV-B
STAIR-1
STAIR-2
```

跨楼层连接必须使用同一个编号。

例如：

```text
1F-ELEV-A
2F-ELEV-A
3F-ELEV-A
```

这样系统才能知道它们是同一个电梯。

## 9. 无障碍路线规范

边增加属性：

```text
accessible = true/false
```

对于轮椅路线：

- 不走楼梯
- 优先走电梯
- 避免狭窄通道
- 避免台阶区域
- 避免不平整区域

## 10. 地图版本管理

每次地图更新都应该生成版本。

建议：

```text
v1.0 初始版本
v1.1 新增药房路线
v1.2 关闭施工走廊
```

路线查询时必须指定当前启用版本。

## 11. 运营备注

建议支持陪诊员经验备注。

例如：

```text
检验科早上人多，建议先取号。
住院部晚上只能走东门。
轮椅患者不要走 2 号电梯，空间小。
报告打印机在药房旁边。
```

这些内容对陪诊业务非常有价值。
